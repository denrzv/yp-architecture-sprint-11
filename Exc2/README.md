# Exc-2

## Разделение компании на домены

Учитывая распределённую природу бизнеса компании, а также будущее присоединение дополнительных направлений, можем выделить следующие домены:

* Финансовый домен (финтех-сервисы) - обработка финасовых транзакций, платежей, интеграция с банками
* ИИ-домен - обработка медицинских изображений, предиктивные модели диагностики
* Медицинский домен - хранение и обработка медицинских данных, клиники
* Домен аналитики - информационный портал, отчётность, менеджмент головного офиса

При разделении на домены опираемся на событийную модель для более низкой связанности.

## Основные преимущества: 

* Структурирование по ответственности
* Более чёткое разделение на направления
* Гибкость при масштабировании процессов
